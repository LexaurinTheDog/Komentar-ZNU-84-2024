# Komentář k zákonu č. 84/2024 Sb., o trhu s nevýkonnými úvěry

Otevřený komentář k zákonu o trhu s nevýkonnými úvěry — § po §: doslovné znění, výklad, kazuistika, protiargumenty a praktický závěr; oprávnění spravovat nevýkonný úvěr, správce nevýkonného úvěru a povolení ČNB, povinnosti věřitele a obchodníka s úvěry, pravidla jednání vůči dlužníkovi, dohled ČNB a přestupky.

Konsolidované znění: dokument e-Sbírky `SB-2024-00084_2024-05-01`.
